SeatSync Examination Portal

Smart Examination Seating

Upload department-wise student data and generate an organized examination hall seating arrangement.

Upload Student Data

Select one or more department files containing student information.

You can select multiple files, such as CSE.xlsx, ECE.xlsx, IT.xlsx and BME.xlsx.

Required Student Details

Every uploaded file must contain these four columns:

  • Register Number
  • Name
  • Department
  • Year

Each file can contain students from 1st, 2nd, 3rd and 4th year.

Seating Rule

SeatSync will automatically arrange students so that:

  • Students from the same year will not share a bench.
  • Students from different years can share a bench.
  • A bench can contain 1 or 2 students.
  • Department does not restrict bench sharing.
